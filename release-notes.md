First release of Lux. Find the pieces in the dark and put the letters back together.

Which APK should I download?
- app-arm64-v8a-release.apk: if you're not sure which one to install, it's probably this one. It works on almost all modern phones.
- app-armeabi-v7a-release.apk: for older 32-bit phones.
- app-x86_64-release.apk: for emulators and rare Intel-based devices.

Install: download the APK, open it, and allow installs from unknown sources if your phone asks.
